🗂️ Backup & Restore

Even with Multi-Device Sync connected, keep exporting backups regularly (e.g. daily) and keep the file somewhere safe (email it to yourself, save to USB/Google Drive/etc). Sync protects you from devices disagreeing with each other — it doesn't protect you from a mistaken erase or a lost internet connection. If sync isn't set up on this device, this is your only protection: unbacked-up data cannot be recovered if this device is lost, damaged, or its browser data is cleared.

🔒 Backup, restore, and erase are restricted to Admin accounts — a backup file contains everything, including employee login PINs, and restoring/erasing replaces all data on this device.

The .html backup is a complete, self-contained working copy of the app with today's data already loaded in — open it directly (double-click, or drag into a browser) and it works immediately, no import step needed. The .json backup is smaller and is what "Import Backup" above expects.

"Erase All Data" and "Reset Everything" now do the exact same complete wipe — every module, including Accounting & Partners, Claims, and shop settings, goes back to zero. If Multi-Device Sync is connected, the shared cloud copy is cleared too so this device won't quietly re-download the old numbers next time it opens.

⏱️ Auto-Backup

Automatically downloads a backup once the interval below has passed — but only while this app is actually open in a browser tab; it can't run in the background or while the device is off/closed. Your browser may ask for a "multiple downloads" permission the first time.

📊 Storage Usage

Two separate limits matter here: this browser's own local storage (roughly 5-10MB, varies by browser, holds everything on this device) and — if Multi-Device Sync above is connected — a 5MB ceiling per shared data bundle below. Getting close to either doesn't crash the app by itself; it just means the next save may fail to reach the cloud (it still saves on this device either way) until something's freed up.

🔒 App Access Code

An extra lock screen shown before anyone — even before the employee login screen — can see or use this app at all. Useful if you're worried about the link or file reaching someone it wasn't meant for. Honest limits: the code is hashed, not stored in plain text, but this is a deterrent against casual or opportunistic access, not real security — anyone able to read this app's own source code has everything needed to route around it, which is true of any check running client-side. The employee PIN system below is what actually controls who can log in and what they can do, and stays in effect either way.

🏛️ Bank Feed

Bring in your bank statement, then categorize each line against a Chart of Accounts entry — that's all it takes. Categorizing immediately posts a balanced Journal Entry against your Bank Account, so it flows straight into the General Ledger and Trial Balance, and into the Profit & Loss if it's Revenue or Expense. Clearing a category removes that entry again.

📥 Upload Bank Statement (.csv)
